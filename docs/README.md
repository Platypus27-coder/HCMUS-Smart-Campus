## 🎯 TIÊU CHUẨN ĐẠT ĐIỂM TỐI ĐA (CURATED AGENT ACCEPTANCE CRITERIA - PAGE 15)

Để đạt điểm tối đa ở hạng mục **Knowledge Base & Supporting Materials (12 điểm)** và **Room Configuration (5 điểm)**, mỗi Agent phải đạt các mốc số lượng tham chiếu:

- **📄 Documents (Tài liệu):** $\ge$ **8 documents**, dung lượng ký tự $\ge$ 3.000 ký tự, định dạng PDF/Word (4 điểm).
- **🖼️ Images (Hình ảnh):** $\ge$ **10 images**, độ phân giải $\ge$ 720P (khuyến nghị 1080P/1600x900), không watermark (3 điểm).
- **🎬 Videos (Video):** $\ge$ **4 videos**, thời lượng $\ge$ 30 giây, MP4 $\ge$ 1080P (3 điểm) — *Nếu dung lượng nặng/chưa kịp quay thì ghi nhận rõ trạng thái hoãn sản xuất kèm kịch bản chi tiết trong `video_resources.md`*.
- **❓ Q&A (Hỏi - Đáp):** $\ge$ **15 Q&A entries** có gắn tag category và bật tính năng default-room Q&A (2 điểm).
- **🏷️ Naming Convention (Đặt tên file):** Phải đặt tên mô tả nội dung có nghĩa, **cấm đặt tên dạng số thứ tự thuần túy** (`1.pdf`, `2.pdf` - bị trừ 0.5 điểm cho mỗi file).
